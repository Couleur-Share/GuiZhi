# MyGo 壳灰度：真机验证清单

**状态：清单，尚未在真机上执行。** 沙箱（无网络、无声誉服务、无杀毒软件、不是浏览器下载）验证不了下面这些项。
这些项里 A、B 任何一项失败，都应推迟灰度发布；C、D 失败则缩小灰度范围或补功能说明。

## 环境

- 一台真实的 Windows 11 x64 机器（不要用开发机的主用户目录：先备份 `%APPDATA%\GuiZhi`，或新建一个普通用户账户）。
- 联网，系统自带的杀毒软件（Microsoft Defender）保持开启、SmartScreen 保持默认（「检查应用和文件」开启）。
- 灰度安装包必须**通过浏览器从 GitHub 预发布页下载**（会带来 Mark-of-the-Web），不要从本机拷贝。
- 记录安装包 sha512 与 Release 页面上的值一致。

## A. SmartScreen 与杀毒软件（决定能不能发的最大未知）

| 编号 | 做法 | 通过标准 | 记录 |
|---|---|---|---|
| A1 | 浏览器下载安装包，双击 | 能看到 SmartScreen「已保护你的电脑」或直接运行；若拦截，「更多信息 → 仍要运行」可见 | 截图拦截界面与发布者显示（未签名应显示「未知发布者」） |
| A2 | 安装完成后首次启动 `GuiZhi.exe` | 不被 Defender 隔离或删除；没有「威胁已删除」通知 | Windows 安全中心 → 保护历史，截图 |
| A3 | 把安装目录里的 `GuiZhi.exe`、`mygo-sqlite3.dll` 手动扫描一次（右键 → 使用 Microsoft Defender 扫描） | 无检出 | 扫描结果 |
| A4 | 若装有第三方杀毒软件（360、火绒、腾讯电脑管家等），重复 A1–A2 | 同上；不拦截 `mygo-sqlite3.dll` 的加载 | 软件名与版本、拦截提示截图 |
| A5 | 在 VirusTotal 上传同一个安装包（只上传灰度包，不含用户数据） | 检出数不明显高于 Electron 版安装包（对照上传 Electron 版同一页） | 两份报告链接 |

失败时的处理：被拦截只意味着需要用户手动放行，要在发布说明里写明；被删除或隔离则视为阻塞，需要签名或向厂商提交误报后再发。

## B. 升级路径（带数据，真机）

| 编号 | 做法 | 通过标准 |
|---|---|---|
| B1 | 起点：真实 Electron 0.28.0 + 有数据的库，开启「开机启动」，关闭应用 | 记录库条目数、集合/标签数、设置 |
| B2 | 安装灰度包覆盖 | 向导走完；备份提示出现一次（非更新方式）；安装完成后「运行归知」勾选可启动 |
| B3 | 首次启动后核对 | 条目数、集合/标签与 B1 一致；界面语言、主题与 B1 一致（localStorage 一次性导入）；没有首次引导弹窗 |
| B4 | 重启电脑 | 开机启动项带 `--hidden`：应用启动但窗口不显示；托盘图标可见；点托盘图标能打开窗口；再次手动启动不会开出第二个实例 |
| B5 | 在 Electron 版里先选「预览通道」，用真实 GitHub 预发布做一次应用内更新 | 点「检查更新」→ 发现灰度版 → 下载 → 安装 → 向导走完 → 点「完成」→ 新壳窗口出现 |
| B6 | 回退：用 Electron 0.28.0 安装包覆盖灰度包 | 库、设置不丢；Electron 版能正常打开同一个库 |
