# 围绕本文提问

在文章头部点击 **围绕本文提问**，可以保留阅读位置，在右侧连续提问。选中正文、文字稿、OCR 或论坛讨论中的文字，也可以选择 **解释这段** 或 **围绕这段提问**。网页快照和 AI 阅读页支持相同入口。

点击入口仅打开面板、预填问题；点击发送后才调用现有问答模型。选段最多 4000 字，问题最多 8000 字。编辑中的正文需要先完成保存；纯图片或没有转写文字的音视频需要先获得文本。

## 联网与来源

- 新对话默认开启联网查证，可按会话关闭。此默认值不改变 AI 阅读页生成的联网设置。
- 复用设置中的 Tavily／AnySearch 服务和现有加密密钥；未配置时可前往配置，或关闭联网后发送。
- 每轮最多两组搜索词，每组最多五个结果；去重后最多采用五份有效正文，最多补抓三页。查询和补抓串行执行，搜索总时限 90 秒，单次补抓 20 秒。
- 搜索失败或没有有效正文时，仍结合本文解释，并显示 **未完成联网查证**。部分成功会保留可用资料与不足提示。搜索成功本身不表示结论已得到证实。
- 回答区分原文、讨论或生成内容、联网资料与推断。点击引用编号可以查看保存的摘录，再定位到原文或打开网页。

## 上下文与历史

本文问答按文章 ID 绑定，不通过标题从全库检索。优先参考当前阅读视图和选段；长文在本文内部按段落匹配，并保留邻近段落。同一条目的原文可以作为补充，其他文章不自动加入。

快照和 AI 阅读页绑定当前版本。会话保存选段、版本标识、内容指纹及实际使用的摘录；版本缺失或原文变化时不静默替换历史依据。旧 AI 阅读页通过可信文档生成器提取实际阅读文本，其原文和既有参考资料分别标注。

对话自动保存在本地 SQLite，文章内恢复最近对话，也能在 **AI 问答 → 历史会话** 查看。本文会话带有文章标题，可返回文章。关闭面板不取消生成；切换文章或会话会停止当前本文请求，并保留已有输出。生成过程中定期保存检查点，恢复未完成记录时标记为中断。

重新回答使用原问题、选段和保存的上下文，并重新查询联网资料；该轮及后续轮次按现有问答语义重建。删除文章不级联删除问答历史，但需恢复文章才能继续提问。保存失败保留当前记录并提供重试。

## 实现与验证

会话表通过幂等迁移增加 `scope`、`item_id`、`article_title`、`options_json`，原有记录默认属于知识库问答。无筛选参数的会话列表接口保持兼容；文章会话支持按文章过滤。

新增 `articleAsk.context`、`articleAsk.search` 和 `articleAsk.cancelSearch`。数据库、文件、密钥和网页抓取留在主进程；模型调用复用现有问答场景的代理与用量记录。搜索取消按调用窗口和请求标识隔离。

iframe 保持 `sandbox="allow-scripts"` 和原有 CSP，只有固定可信桥接脚本传递纯文本、矩形与定位结果。父窗口验证消息源、实例标识和字段；不增加同源权限或任意代码执行能力。

数据库备份自然包含会话及来源摘录，搜索密钥不进入会话、数据库备份或普通导出。

验证入口：

```powershell
pnpm typecheck
pnpm test:unit
pnpm lint
pnpm build:isolated
pnpm shot --steps D:/Project/GuiZhi/apps/desktop/tests/e2e/article-ask-frames-shots.mjs --out D:/Project/GuiZhi/artifacts/article-ask-frames
```

离屏交互脚本使用临时数据目录，AI／搜索服务由测试 IPC 模拟，覆盖文本划词、iframe 桥接、来源版本、搜索失败、历史恢复和全局入口。该验证不代表真实第三方模型回答质量、真实搜索服务可用性或已安装版本的行为。
