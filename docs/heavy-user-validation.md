## 性能样本

固定生成器覆盖 1k、10k、50k 条资料及至少 50k 个 64 维向量。测试机器为 Intel Core Ultra 9 185H、32 GB 内存，使用隔离合成数据库。

| 10k 条资料的 Electron 检查 | 结果 |
| --- | --- |
| 列表 IPC 热态 P95 | 27.8ms |
| 处理中心数据 IPC 热态 P95 | 66.9ms |
| Wiki 候选预览热态 P95 | 64.1ms |
| Wiki 候选预览冷态 | 约 1.74 秒 |

这些结果不代表生产用户库性能。HNSW 在本机运行时不兼容，实际走精确检索回退；不能将回退结果作为 HNSW 加速性能或真实 WASM 内存曲线通过的证据。

| 检查 | 证据 |

真实服务测试使用合成资料和临时数据目录。降级是注入延迟，平台已有正文是合成夹具；未验证真实视频下载、ASR、登录态采集、全部平台、全部模型，以及真实用户历史资料升级。FTS 降级使用标题关键词，不表示独立文字稿正文已纳入 FTS。
