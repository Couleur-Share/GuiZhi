## 2026-10-08 阶段 2 交付

| 范围 | 当前行为 |
| --- | --- |
| 桌面阅读投影 | 明确选库；读取当前编辑正文、摘要、分类、标签与安全来源链接。删除和移库通过完整扫描补偿；本地图片改写为不透明同步 ID，不上传原始 DB ID、访问 URI 或配置 |
| 上传队列 | 上传前原子落盘密文；无变化跳过；网络失败复用原密文，逐对象持久化断点；提交回执丢失后按清单哈希确认；旧云端版本不被盲目覆盖 |
| 可信配对 | 五分钟邀请；二维码 fragment 携带一次性秘密；HKDF 分离证明与封装子密钥；PC 验证设备/凭证绑定后封装内容密钥和可信清单检查点 |
| 独立云服务 | 单独 `reading-main` 进程与 `reading.db`；拒绝误用收集数据库；PC 写权限、手机只读权限、不可变密文对象、原子清单、容量与频率限制；默认禁用请求日志 |
| 桌面入口与保护 | 安全存储加密凭据，`.machine/reading-sync` 不在迁移和备份白名单；默认关闭实验入口；清空阅读清单、撤销手机分别确认；备份恢复前中断并冻结同步 |

当前为有界、手动同步：选择范围改变必须先保存；每次内容变化重建整个加密快照，尚未复用未变对象的历史密文，也没有自动变更监听。正文与图片合计最多 40 MiB、全部对象最多 10,000 个，单图片最多 8 MiB；不支持的本地图片或缺图会保留旧云端版本并返回失败，不会假报完整。视频原文件不上传。

服务每个阅读库最多保存 256 MiB 密文、20,000 个对象、一个阅读手机；服务最多 100 个库。无引用对象至少保留 24 小时，新增对象时才回收；当前清单引用对象不会回收。逐来源地址每分钟最多 240 个请求，限流后手动等待 60 秒再重试。暂存确认超过 12 小时后整批重新确认并续租，避免长时间断网后的悬空引用。服务只提供当前完整清单，旧引用不可再下载；手机取得新清单前保留上一个完整可用版本。

部署参数与协议在[阶段 2 接线文档](./mobile-reading-phase2.md)。当前未部署、未上传真实资料、未提交或发布，未生成新版本安装包。
