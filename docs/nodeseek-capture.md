# NodeSeek 验证后自动采集

当前源码新增 NodeSeek 帖子采集，识别 `https://www.nodeseek.com/post-帖子编号-页码`，自动回到主楼并逐页读取回复。来源统一为第一页，同一帖子不同页不会作为不同来源重复收集。

## 使用流程

1. 在「快速采集」提交帖子链接。
2. 遇到网站验证时，打开失败任务详情，点击「验证并自动采集」。也可从任务行的「网页验证」入口进入详情。
3. 在归知打开的 NodeSeek 窗口中完成验证。目标帖子可读后，窗口关闭，原任务自动重试，采集主楼与各页回复并生成讨论总结。

验证等待最多 5 分钟，可以在归知取消或直接关闭验证窗口。取消和失败不会触发自动重试。网站会话由归知自己的 Electron 分区保存，不读取日常浏览器资料，Cookie 不经过 IPC。网站要求再次验证时，需要重新完成验证，不能保证一次验证永久有效。

## 内容与访问边界

- 回复按真实楼层排序、去重，首页的置顶回复不会重复保存。
- 任意分页请求失败时整次任务失败，不把首页误报为完整结果。最多采集 100 页；超过时明确标注后续回复未入库，讨论总结同样注明缺失。
- 验证页、空白页、主楼缺失、楼层正文或时间缺失均不作为成功内容保存。
- 保留 HTTPS、沙箱、证书校验及既有内网地址校验；新增浏览器边界仅允许 NodeSeek 官方主机和 `challenges.cloudflare.com`，不允许任意子域、非默认端口或 URL 凭证。
- 此次支持帖子采集，不增加 NodeSeek 搜索发现、账号操作或自动解验证码能力。
