# MCP 接入

「设置 → MCP 接入」：独立进程只读打开本机数据库，归知不必正在运行。

## 能力

- 两个工具：`search_knowledge`（FTS 全文检索）、`read_item`（返回 AI 交接稿全文，见 [功能说明](./features.md)）
- Cursor 一键写入 `~/.cursor/mcp.json`；Codex 提供 `codex mcp add` 安装命令
- 可按知识库限制可见范围（私人日记等可排除）；改完即时生效，无需重启 IDE 侧的配置文件缓存

## 使用注意

- 检索默认走召回模式（适合模型给出的词组 / 整句），不是精确短语匹配
- 归档条目仍可被搜到（归档只是「处理完了」，不是移出知识库）
- 配置里的路径是绝对路径；应用换安装位置后需回设置页重新写入一次
- 目前只有 FTS，没有语义检索；也没有任何写操作（不能通过 MCP 发起采集）

客户端目前覆盖 Cursor（一键安装）与 Codex（命令）。更多边界见 [已知限制](./known-limitations.md)。
