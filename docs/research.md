# 近期研究

研究工作区将站内搜索、有限文字精读、报告和历史比较保存在本地研究记录中。只有主动保存报告、保存研究摘录或完整导入原文，才写入正式知识库。

## 使用

1. 打开侧栏「研究」，输入自然语言问题，选择 7 / 14 / 30 天和来源。
2. 快速模式直接搜索。深度模式自动规划并精读，进度区可展开查看计划与每次查询的实际覆盖。
3. 查看候选准入说明和「材料与引用」。日期未知、窗口外和偏题内容仍可查看，但不会混进近期结论。
4. 手动生成报告。点击报告的外部引用编号，打开本次冻结的证据原文；补采或精读更新后，旧报告继续可读并提示「证据已更新」。
5. 用「重新研究」开始同一序列的新一轮，默认复用计划；「重新规划并研究」会调用一次规划。独立新建的同名问题不会自动合并。
6. 在「本轮变化」选择历史基线，查看确定性差异。比较本身不调用模型。

| 预算 | 快速 | 深度 |
| --- | --- | --- |
| 查询 | 原问题 1 条 | 最多 3 条，始终保留原问题 |
| 每个平台 | 1 页 / 20 条 | 所有查询合计 3 页 / 60 条 |
| 自动规划 | 无 | 最多 1 次，30 秒，无自动重试 |
| 自动精读 | 无 | 最多 6 条，优先覆盖各来源 |
| 精读时限 | — | 单条 180 秒，整批 10 分钟 |
| 报告摘录字符预算 | 12,000 | 32,000 |
| 报告 | 手动生成 | 手动生成 |

规划和报告复用研究场景对应的主文本路由，并记录研究用量。没有模型、计划非法或规划超时会回退原始查询。报告没有合格近期证据时不会调用模型。

## 材料与证据

策略 `research-policy-v2`：相关性至少 30；明确实体问题要求实体匹配；同平台同作者最多 3 条，每平台最多 10 条，总计最多 30 条。未知作者分别处理。相同平台内容 ID / 规范 URL 去重，已取得文字的相同哈希合组并保留来源链接。仅标题相似属于聚类，不代表独立印证。

高、中置信且在窗口内的日期才是近期证据。低置信或未知日期最多引用 3 条，并限于待核实或材料限制。窗口外候选不进入近期结论。发布时间与采集时间分别保存；互动缺失不补成零。

搜索摘要、正文、视频文案、字幕、评论、本地背景分别标注。每份材料最多保存 200,000 字符；达到上限会提示截断。报告只取得按问题选择的片段，保存上限与模型摘录上限各自提示。字幕保留 cue 时间，普通段落保留位置编号。评论最多读取 20 条、去重并限制同作者，报告最多使用其中 3 条；评论只能说明该作者表达的观点。

每次报告保存独立操作 ID、快照 ID、策略版本、摘录、覆盖状态和编号。取消、删除或替代操作后，迟到响应不能覆盖当前报告。编号不存在、模型自行输出链接、结论缺少引用时拒绝新报告，保留旧版。**这些检查不是事实核验，仍需检查结论是否忠于原文。**

## 平台精读范围

| 平台 | 自动精读 | 未覆盖部分 |
| --- | --- | --- |
| 小红书 | 登录态正文 / 文案，最多 20 条评论 | 不资产化配图、不 OCR；视频文案不代表口播 |
| 抖音 | 登录态文案，最多 20 条评论 | 不下载视频或音频、不转写、不 OCR |
| 哔哩哔哩 | 元数据、已安装 yt-dlp 取得的发布者字幕，缺失时尝试平台自动字幕 | 不读取评论；不安装依赖、不下载音轨、不调用转写或媒体总结 |

自动字幕可能有识别错误。图片缺少可读文案、视频无字幕时，当前精读不足以描述图像或完整口播。平台登录、验证、限流和改版可能导致部分覆盖，不能将成功返回或达到采样上限表述为完整覆盖。没有新增搜索引擎兜底、平台或 Python / Playwright 运行时。

## 比较与已有知识

基线默认是同序列最近一次有结果的已结束记录；失败和取消记录不自动成为基线，部分覆盖会标注。变化由程序计算，包括新增发现、两次均出现、已取得正文变化、两次都有有效数值的互动差、窗口内未检索到、离开窗口和无法判断。

新增发现不等于新发布；未检索到不等于删除。来源失败、计划或策略变化、采样限制会阻止缺失趋势判断。没有自动热度上升或下降结论。

「关联已有知识」默认关闭。开启后必须主动选择一个知识库或全部知识。报告生成时使用现有 FTS 与 embedding 索引混合检索，不重建索引；语义路径失败则回退 FTS。范围先进入查询条件，异步检索后再次校验；排除回收站和本序列保存的报告，包含归档条目。最多 6 条，每条 1,000 字符，独立编号 `L1…`，不计入近期外部来源数量。本地内容标明版本时间，不冒充刚抓到的外部原文。

## 保存、恢复与回退

「保存研究摘录」只保存已取得文字及出处、定位和采集时间，并明确标注摘录。「完整导入原文」沿用导入队列，可能触发原有媒体处理。报告入库附带实际引用的文字和来源，删除研究记录后仍可独立阅读；不自动改旧正文或编译 Wiki。

每页搜索、每条精读完成后持久化，网络调用不持有数据库事务。退出会取消任务并清理字幕临时目录；重启保留已取得材料，不自动访问网络或调用模型。「继续未完成部分」复用已经成功的单元，逐条精读也可重试。

数据库迁移为 `0025-research-evidence`、`0026-research-documents`、`0027-research-series`，新库 schema 同步。旧研究保持旧版内容，不在迁移中评分或调用模型。桌面升级在修改 schema 前调用现有 `pre-update` 备份机制，备份失败中止初始化。回退使用旧代码兼容的升级前备份，不逆向删除字段。本轮不包含生产库试迁移、发布、推送或定时研究。

## 开发验证

固定中文问题、原文和响应见 `apps/desktop/tests/fixtures/research-cases.json`。固定响应验证编排和引用格式，不能证明真实模型总能忠于片段。读者仍应人工核对结论与证据。

定向测试覆盖准入、预算、快照、取消、字幕临时目录、范围、比较和保存；全量门禁使用隔离数据库及测试配置。离屏截图通过仓库 `scripts/screenshot.mjs` 的研究步骤脚本生成，不操作用户可见窗口。

真实平台验收必须另外记录平台、时间、登录状态、查询、返回层级与限制。测试替身和界面截图不等同于真实平台可用性，也不等同于实际模型语义验收。
