# Cloudflare 后备采集

在「设置 → 采集与转写 → Cloudflare 后备采集」启用 FlareSolverr，识别到验证页后会自动获取正文。旧失败任务可点击「自动验证并采集」。普通拒绝访问或限流不会触发此后备服务。

服务返回的 HTML 直接进入归知正文提取和入库流程，不拿 Cookie 重新访问网页。每次采集创建独立会话，结束或取消时销毁；失败会显示原因并允许重试。服务连接成功仅表示控制接口可用，不保证网站验证一定通过。

## SSH 服务器

使用已有 SSH 配置中的主机别名和密钥，例如配置中已有的 `my-server`。填写服务器回环接口的端口（默认 `8191`），点击「测试连接」，再保存。

归知调用系统 `ssh`，使用 `BatchMode` 自动建立仅绑定本机 `127.0.0.1` 的临时端口转发，完成后关闭自己的隧道。服务仍只需监听服务器回环地址，无需对公网开放。归知不保存 SSH 密钥、密码或浏览器 Cookie；首次使用前须已完成正常的 SSH 主机密钥信任与密钥登录配置。

网页网址会发送至用户明确配置并信任的服务器，由该服务器的浏览器访问，不使用归知的本机网络代理。入口与返回网址仍经过归知 URL 安全检查，返回页面须同源并遵守采集目录范围；**远端浏览器内部的导航、DNS 和子资源访问限制由 FlareSolverr 服务所在环境负责**，不能把客户端的返回网址检查当作远端逐跳 SSRF 防护。仅连接自己管理且已限制网络访问的服务。

## 本机服务

先运行 FlareSolverr，再选择「本机服务」，填写其本机回环接口端口。归知不下载安装或启动该服务；浏览器代理和网络隔离由服务配置。

官方协议：[FlareSolverr](https://github.com/FlareSolverr/FlareSolverr)。后备采集只接受不含凭据的 HTTPS 标准端口网址，网页上限 10 MiB，单次 CF 验证上限 60 秒。未启用服务时保留手动验证入口。
