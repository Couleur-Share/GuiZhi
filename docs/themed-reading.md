# AI 重构阅读

AI 重构阅读对正文进行提炼、重组、扩写与可选的联网查证，再根据内容设计独立 HTML。正文和讨论总结分别保存成品；原始 Markdown 继续用于搜索、问答、编辑和 Markdown 导出，不被扩写内容覆盖。

## 阅读与编辑

未生成时显示渲染后的原文，点击「生成 AI 阅读页」开始。已有成品时重新打开默认进入「AI 阅读」，可随时切回「原文」。Markdown 源码只在「编辑原文／编辑讨论总结」中出现，不增加第三个阅读版本。

完成编辑返回原文。编辑只替换选中的内容段，保留其他正文、讨论、图片和媒体元数据。保存失败保留编辑内容并提示重试；切条目时的未完成编辑暂存在当前应用会话内。原文更新后显示过期提示，用户自行决定是否更新 AI 页。

AI 阅读和原文分别记录滚动位置与目录状态。生成完成不会抢占正在编辑的界面或另一个条目。网页快照、来源网页使用独立入口名称。

## 配置与生成

文本模型沿用 mainText → fastText → 默认聊天模型；图片使用 imageGen 路由。联网搜索在「模型服务 → 模型路由 → 联网搜索」中配置，支持模型服务原生搜索、Tavily 与 AnySearch，也供围绕本文提问使用。Tavily 与 AnySearch 分别保存密钥，原生搜索复用主文本模型的地址和凭证，无需额外搜索密钥。选择服务并保存即可切换；连接测试先验证候选配置，通过后保存，失败保留原服务和密钥。搜索服务密钥只由主进程处理，安全存储不可用时只留在本次进程内存，不明文落盘，也不进入普通备份或导出。

默认关闭联网，每次生成仍可单独开启。未配置时可前往设置，或主动关闭联网后生成。AI 阅读联网失败不会自动降级，原文和上一版继续可读。

流程为：完整分批理解原文 → 全局提纲 → 搜索与读取资料 → 按章节撰写编辑稿 → 自由 HTML/CSS 设计 → 图片处理 → 验证发布。长文分批处理全量内容并归并笔记；设计调整可以复用内部编辑稿。

每批研究最多 3 个查询、每个最多 5 个结果，去重后最多读取 8 篇网页；资料不足时最多再补查两批。只发送研究问题和关键词；Tavily Search 固定 basic 深度、关闭 auto_parameters，优先使用 raw_content；AnySearch 固定调用 `/v1/search` 并请求 Markdown，检查 HTTP 与业务码，使用 content 正文。选中的来源仍尝试安全网页采集。搜索摘要不能作为查证完成的依据。记录实际取得正文、失败资料、获取时间与已知发布日期。搜索服务密钥以 safeStorage 密文保存在 `.machine/reading-search.json`，旧 Tavily 配置自动兼容。接口依据：[Tavily Search](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[AnySearch](https://www.anysearch.com/docs)。

模型服务原生搜索使用 OpenAI 兼容的 `/v1/responses` 与 `web_search`，要求实际完成搜索并返回公开网页来源。设置中的“已配置”表示主文本模型配置可用于发起请求，能力是否受支持应以连接测试为准；不凭模型名称判定。请求采用流式传输、180 秒超时、8 MiB 响应上限与 8192 输出 token 上限。只提取工具来源和 `url_citation`，不把生成的回答当作网页正文；来源进入已有采集、查证及引用流程。未执行搜索、响应不完整、无有效来源或服务不支持时明确失败，不自动切换服务或关闭联网。已有默认开关和外部搜索密钥保持不变，模型凭证不会复制到搜索配置。搜索请求计入任务请求数，模型 token 按 AI 阅读／问答场景记录；服务端工具调用费用以供应商账单为准。接口依据：[OpenAI Web search](https://developers.openai.com/api/docs/guides/tools-web-search)。

勾选“生成主题元素图片”后，至少生成并展示一张主题图片，数量不超过所选上限（1–5 张）。SVG 图解和原有图片不能替代本次生图要求。规划未提供有效图片时明确失败；设计漏放图片时由程序补上一个展示位置；生图失败显示部分完成，继续任务只补失败图片。关闭生图时不发送新生图请求。已有图片按内容需要复用，不要求全部出现在成品中。

## 自由设计与可信交互

模型可重拟标题、调整结构、加入解释和比较，选择不同布局、配色、图文比例及安全 SVG 图解。新页面不显示逐条引用编号、核对原文、原文归纳／推导标签或完整原文附录。

模型只输出 HTML/CSS 与交互定义。页内导航、原生折叠、标签、筛选、情景选择和计算器由固定可信运行时执行。情景只切换已生成解释；算术解析器支持加减乘除、括号、min/max、输入边界和单位，不使用 eval。模型脚本、事件、宿主 API 和外部资源请求均禁止。

新清理规则允许 Grid、Flex、渐变、CSS 变量和响应式布局。清理前后正文变化、失效锚点、缺失素材或无效工具会阻止发布，并最多进行一次设计修复。完整页面设计有独立的输出额度与超时，网络失败保持检查点供恢复。

## 调整与参考资料

- **仅调整设计**：复用编辑稿与研究资料，只调整页面视觉和所需图片，不重新搜索或写作。
- **调整内容与设计**：以当前稿件为基础修改，只有新增查证问题才补充研究。
- **按最新原文重做**：从最新正文或讨论总结重新执行完整流程。

旧页面无独立编辑稿时提供「升级重构」，验证成功才替换。条目标题不会因页面重拟标题而自动修改。

应用工具栏「参考资料」展示本次实际使用的外部来源、链接和获取时间。导出为离线单文件 HTML，内嵌图片、可信交互与深浅色切换；文末参考资料默认收起。不会附带原始 Markdown、内部研究全文、密钥或应用桥接。

## 任务、备份与兼容

任务显示实际阶段、文本／搜索／生图请求数和取得正文数，不估算整体百分比或完成时间。理解笔记、搜索结果、研究资料、编辑稿和设计分别保存检查点。恢复时复用成功查询与已完成写作；研究失败可选择「重试联网」或「改为不联网生成」。应用重启不会自动恢复付费请求。

当前版仅在最终验证后原子替换，取消、异常、删除和过期回调不能覆盖现有成品。配图部分失败时文章仍可发布并提示缺图，支持单图重试。当前版、上一版、工作版和任务表继续复用，没有第二份知识条目。

新格式使用 formatVersion: 2。旧自由 HTML、旧结构化专题及其未完成任务沿用原格式读取和续跑，不批量转换。未知格式明确报错。完整备份包含新旧格式数据及引用图片；删除、恢复和清理遵守现有资源引用关系。普通备份不包含机器目录下的搜索密钥。

阅读页生成默认不启用联网搜索（已有搜索密钥也不会自动开启）。在「设置 → AI → 联网搜索」可切换「生成阅读页时默认联网搜索」，立即保存；每次新建或调整阅读页仍可单独选择是否联网。此默认值不会修改正在执行或等待恢复的任务。搜索开关随本机搜索配置保存，安全存储不可用时仅本次运行有效。

## 验证方式

运行 pnpm typecheck、pnpm test:unit、pnpm lint 和 pnpm build。UI 使用最新构建和 pnpm shot 的隔离用户目录。新增 reading-reconstruction-* 测试涵盖自由设计、安全解析、分段编辑、研究失败、检查点、备份和离线工具。

真实文本模型验收脚本 reading-reconstruction-live.ts --run-offline 使用保存的鱼油／啤酒原文副本，不写用户库。reading-reconstruction-resume.ts 从失败稿恢复设计；reading-reconstruction-render.ts 只重绘保存结果，不调用模型。真实在线验收需要对应服务的有效凭证；原生搜索使用模型服务凭证。`native-search-settings-shots.mjs` 使用真实隔离 Electron 与本机 Responses 测试服务，覆盖成功、失败保留旧配置、重试、持久化与深浅色窄窗口，但不证明真实 CPA 上游可用。详见 [验收记录](./themed-reading-validation.md)。
