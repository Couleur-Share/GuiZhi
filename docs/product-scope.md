# 产品边界

2026-11-07 依据全项目评审确定，用来回答「这个功能该不该做、该做到什么程度」。范围变化时先改这份文档。

## 定位

归知是本地优先的个人知识库，核心闭环是 **采集 → 整理 → 检索 → 问答**：把网页、平台内容、本地文件收进来，用合集、标签和全文检索整理与找回，再围绕资料提问、编译 Wiki。AI 服务于这个闭环，不单独成为产品方向。

官方只支持 Windows 11+ x64，见 [已知限制](./known-limitations.md)。

## 核心范围：持续投入

- **采集**：网页正文与文档站点批量抓取、本地文件、主流视频与图文平台、论坛帖，采集队列与去重。
- **整理**：条目编辑、合集、标签、批量整理、处理中心。
- **阅读**：正文与网页快照、论坛楼层、本文问答、AI 重构阅读（v3）。
- **检索与问答**：全文检索、语义检索（精确扫描）、全库问答与本文问答、证据与引用。
- **Wiki**：全文编译、历史升级、人工编辑保护。
- **数据安全**：备份恢复、Markdown 导出、配置迁移、MCP 只读接入。

| 近期研究、平台发现、手机收集 | 已从桌面端移除（2026-11-13，Go 外壳） | 已保存到知识库的报告与摘录不受影响；入口与采集能力不再提供 |

| AI 重构阅读 v1/v2 旧格式 | 只读 | 旧页可阅读、导出、备份恢复，不再生成或续跑；新页只用 v3 |
| HNSW 加速检索 | 已移除（2026-11-07） | `hnswlib-wasm` 在 Electron 主进程无法加载，官方平台始终回退精确检索 |

**冻结**的含义：不新增功能、设置项、IPC 频道或数据表；只修安全问题、崩溃、数据丢失，以及外部平台改版导致的失效。解冻需要先在这份文档写明理由。

**Go 外壳主线（2026-11-13）**：桌面端只维护 Go + WebView2 外壳（`apps/desktop-go`），Electron 版停止维护。上表标「已从桌面端移除」的功能没有迁入 Go 外壳，数据仍保留在库里；Electron 终版保存在分支 `electron-final` 与标签 `electron-final-0.28.x`。要恢复这些功能，先在本文档写明理由并按「新功能准入」重新评估。

**冻结功能的入口规则**（仅适用于 Electron 终版；Go 外壳已移除对应功能）：冻结功能不占一级入口，只对已经在用的用户可见，其余用户经命令面板（`Alt+Shift+F`）进入。

| 功能 | 可见条件 | 其余用户的入口 |
| --- | --- | --- |
| 近期研究 | 已有研究记录，或当前正位于研究模块 | 命令面板「新建近期研究」 |
| 平台发现 | 已保存过发现视图（采集页工具栏按钮） | 命令面板「平台发现」、快速采集里的「浏览博主」 |
| 正文配图设置 | 已配置文生图模型，或正被打开 | 先在「模型服务」配置文生图模型 |

用语：**采集**指把外部内容放进来；**导入**只用于配置与数据迁移；**合集**与「未归合集」指条目的归属；**知识库**只指产品本身和一级模块名。

## 新功能准入

提出新功能时先回答三件事，答不清就不进主线：

1. 服务于核心闭环的哪一步，现有功能为什么做不到。
2. 维护成本：新增几个设置项、IPC 频道、数据表、外部依赖或常驻进程，安装包增加多少。
3. 退出方式：效果不好时能否关闭入口或整体移除，用户数据会怎样。

只为个人基础设施或单个站点服务的需求（自建服务、特定论坛），优先做成默认关闭的可选项，并在状态表里登记。
