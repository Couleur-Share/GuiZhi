# 微信公众号原文排版

粘贴 `mp.weixin.qq.com` 文章链接即可采集；桌面导入和手机提交使用同一适配器。正文同时保存为只读 HTML 来源快照和可编辑 Markdown。侧栏“微信公众号”按来源筛选和统计。

新采集文章默认显示“原文排版”，默认使用“自适应宽度”，随窗口自然换行，按正文字号估算约 36 个汉字的舒适行宽（含边距，范围 560–900 CSS px；窄窗口不超出可用空间）；也可选择“铺满宽度”或固定 390 CSS px 的“原文宽度”。手动选择会保留。原文使用作者配色，没有明确背景时使用白底深色文字；应用外围仍遵循归知主题。

“标准排版”使用归知 Markdown 阅读器，通过“更多 → 切换到标准排版”进入，不再常驻并列切换按钮。编辑正文后，后续打开默认展示编辑后的正文，并标记“正文已编辑”；点击“查看原文快照”可对照来源，再通过“返回编辑后正文”继续阅读修改稿。原文快照保持采集时内容，修改 Markdown 不会同步修改原文排版。“在当前页查找”保持当前排版：原文排版中直接高亮并定位，支持跨样式文字、上一个／下一个匹配和 Ctrl+F；关闭搜索清除原文高亮。

## 阅读布局

文章信息、标签、原文版本、AI 摘要和配图工具默认收在“文章信息与工具”中，点击展开；保存失败和未保存提醒仍直接显示。当前阅读模式、宽度、搜索和编辑入口合并到单行工具栏，补采及 HTML 导出位于“更多”。

使用右上角专注阅读按钮或 Alt+Z 隐藏侧栏与列表，按 Esc 返回；在公众号原文中选择文字后仍可用 Esc 退出。

## 旧文章与来源更新

升级只重新归类已有公众号来源，不联网、不改写正文、标签、集合。没有快照的旧文章显示标准排版及“尚未保存原文排版”说明，点击“补采原文排版”手动采集；列表多选公众号文章可批量补采，进度、取消和逐条结果在导入任务查看。

补采关联原条目，不创建重复知识条目，也不覆盖已有 Markdown。已有快照的内容或排版变化保存为新的来源版本；在“原文版本”中比较并明确采用。采用前保存当前正文版本，同时检查标题和正文是否发生并发修改。只改变图片或样式也会识别为新版本。

## 离线保存与导出

图片按内容哈希保存到本地资产目录，Markdown 与原文共用文件。历史原文版本及回收站仍引用的图片不会被清理。原文阅读不向微信请求图片；资源失败保留占位和原因，使用“重试缺失资源”重新采集并生成新的版本。

“导出原文 HTML”导出当前所选来源版本到新目录，包含 `index.html` 与 `assets/`，可在浏览器离线阅读。不含应用桥接脚本或用户配置。正文链接与来源入口仍需要联网访问。存在缺失资源或降级内容时，导出结果会明确说明不完整。Markdown 导出继续使用编辑后的正文。

加密备份、便携备份和数据目录迁移包含本地图片目录；备份资源枚举覆盖历史原文。旧式单独 `.db` 文件备份本身没有媒体文件，不能作为离线图文的完整备份；恢复后缺图会报错并提供重新补采入口。

## 支持范围与限制

- 保留静态正文布局、边框、圆角、颜色、图片、表格、列表、引用及安全 SVG 几何装饰，不承诺跨设备像素一致。
- 不执行微信脚本；音视频、小程序和交互内容保留说明、可获得的封面与原文入口，不下载音视频。
- 不加载外部字体、外部样式表和 CSS 导入；动态装饰、依赖 CSS 变量及媒体查询的规则可能降级。微信应用外壳及其深色模式转换不在还原范围内。
- HTML 上限 10 MiB；单图 20 MiB；每篇最多 200 个资源、总量 100 MiB；下载并发 4；任务总时限 180 秒。封面计入资源预算。
- 验证、登录、失效和无正文页面返回失败，请打开原文确认后重试，不保存提示页作为成功文章。
- 当前仅为微信公众号生成 HTML 快照，其他网站沿用已有采集行为。

## 开发入口与验证

共享契约位于 `packages/shared/types/web-capture.ts`。迁移 `0031-wechat-snapshots` 新增版本资源关联并回填公众号平台。`main/services/web-capture/wechat.ts` 负责专用采集；`snapshot-sanitize.ts` 使用 HTML/CSS 解析器清理；`snapshot-assets.ts` 原子发布哈希资源；`snapshot-service.ts` 负责读入及导出。

`WebSnapshotPane` 使用不开放同源权限的 sandbox iframe。来源脚本全部移除，CSP 仅授权固定桥接脚本哈希；宿主检查消息来源窗口、实例 ID 与事件结构。恢复、读入、导出重新校验快照。UI 不接收任意文件路径，也不下载图片。

回归测试位于 `tests/unit/web-capture/snapshot*.test.ts` 和 `tests/unit/db/backup-repository.test.ts`。真实网络探针需显式设置 `GUIZHI_TEST_WECHAT_LIVE=1`，可用 `GUIZHI_TEST_HTTP_PROXY` 指定隔离测试代理。离屏流程使用 `tests/e2e/wechat-snapshot-shots.mjs`，先构建，再通过 `pnpm shot --steps <绝对路径> --keep-profile` 运行。

联网探针与截图都使用独立数据目录，不更改用户真实知识库或代理设置。离屏脚本验证全图加载、问题框、宽度、宿主隔离、编辑保护、HTML 离线导出和应用进程重启；测试产物写入指定的截图目录。

## 章节与续读

阅读区右侧留白充足时显示迷你章节线、阅读进度和返回顶部。悬停或聚焦目录可展开标题，当前章节随滚动高亮；目录浮层不挤动正文。窄窗口通过工具栏“目录”按钮打开同一浮层，支持点击章节、Esc 关闭和键盘操作。识别标准标题以及短小、居中加粗的章节文字；无法明确识别时显示说明，不生成猜测目录。

原文阅读位置按条目和来源版本保存到本机，保留最近 100 个版本。保存段落及段内位置，重新打开、切换排版或宽度后恢复；图片加载完成后校正位置。新的来源版本独立记录，避免套用旧版本位置。
