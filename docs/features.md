# 功能说明

2026-09-12 源码改进批次的操作、兼容与验证边界见 [重度使用改进](./heavy-user-improvements.md)，尚未正式发布。

## 采集 · 收进来只要一步

- **快速采集**：快捷键 `Alt+Shift+N`（默认应用内生效，可改为全局）、托盘菜单、顶栏「新建」三种入口；粘贴文本、链接或分享口令自动识别类型，也可开空白笔记
- **拖进来就行**：文本 `.txt/.md`、图片 `.png/.jpg/.webp/.gif/.bmp`、音频 `.mp3/.wav/.m4a/.aac/.ogg/.flac`、视频 `.mp4/.webm/.mkv/.mov/.avi`
- **网页正文抽取**：Readability 抽正文 → Turndown 转 Markdown，全程 SSRF 防护；抓取失败自动降级为「保存链接」
- **在线视频与图文**：见 [采集平台](./capture-platforms.md)。B 站 / YouTube 经 yt-dlp；抖音 / 小红书走专用解析与可选登录采集；配好转写模型后视频可一路做到文字稿 + 结构化总结 + AI 标题
- **论坛帖**：V2EX、LINUX DO、小众软件与 2Libra 保留全部回复；NGA 只保留楼主回复并尽量附带被回复楼摘要；讨论区为卡片列表，可生成讨论总结；NGA 另将主楼与楼主回复里的附件图入库（上限 80 张）
- **导入队列**：并发 2、落库持久化、重启自动恢复、可取消可重试；任务行显示阶段耗时，详情弹窗可复制诊断信息
- **去重**：下载与转写前识别规范 URL／内容 ID，短链先轻量解析，入库前继续检查内容哈希；可打开已有条目、保留正文更新来源或创建副本

## 知识库 · 两种视图，检索优先

- **卡片视图**：虚拟化列表 + 常驻详情面板，中间栏宽度可拖拽
- **列表视图**：全宽表格，列可显隐、可拖拽调宽、服务端分页，详情在全屏弹窗打开
- **范围与整理**：未分类 / 全部 / 收藏 / 归档 / 回收站；知识库 + 标签；侧栏另有「平台」分区（抖音 / B 站 / 小红书 / YouTube / V2EX / NGA / LINUX DO / 小众软件 / 2Libra / 网页 / 本地文件）
- **批量操作**：Ctrl/Cmd 点选、Shift 范围选、跨页选择和冻结全部筛选结果；批量移动 / 归档 / 回收站 / 恢复 / 彻底删除，逐条回执、只重试失败项
- **编辑**：CodeMirror 6 Markdown 编辑与预览双模式，「正文 / 文字稿」双 Tab，防抖自动保存（可关掉改用 `Ctrl+S`）
- **详情阅读**：总结 / 正文 / 文字稿 / 讨论可在面板内查找（高亮 + 上一个/下一个；讨论为过滤楼层）；论坛讨论另有可折叠楼层目录；按条目记住标签、滚动、讨论搜索词与目录开关；「回复 @某人」可跳到被回复楼（未入库或无法唯一定位时给出提示）
- **检索**：SQLite FTS5 中文按字分词 + 英文前缀匹配，BM25 加权排序（标题 > 标签 > 正文）
- **AI 交接稿**：把一条条目序列化成自包含 Markdown，复制到 Cursor / Codex 等对话框；也可另存为文件

## AI

六条模型路由与能力说明见 [模型路由](./ai-models.md)。

支持为正文及讨论总结生成独立的 [AI 重构阅读](./themed-reading.md)：提炼、重组、扩写与可选 Tavily 联网查证，再自由设计 HTML 和可信交互。有成品时默认 AI 阅读，可切回原文并编辑，支持设计调整、参考资料、版本恢复、单图重试与离线导出。

阅读时可使用 [围绕本文提问](./article-ask.md)：支持正文、文字稿、OCR、讨论、网页快照与 AI 阅读页的划词提问，默认联网补充资料，失败时明确标注未查证。会话绑定文章保存，并可从 AI 问答历史查看。

## Wiki · 让条目长成知识网络

- AI 把知识条目**增量编译**为互链的 Wiki 页面（主题 / 实体 / 概念三类）
- `[[链接]]` 经白名单清洗，自动生成反向链接与来源条目回溯
- 全文指纹覆盖标题、正文和独立文字稿，分块提取后增量更新相关页面；支持检查点、暂停、取消与继续。历史升级预览后手动选批，人工页面先审阅更新建议
- **关系图谱**：力导向图展示页面网络，点节点直达页面
- 问答检索融合 Wiki：页面优先命中，读页面时出链与来源成为新线索

## 本地工具链 · 应用内一键安装

三个可选外部工具都不打包进安装包，需要时在「设置 → 常规 → 采集」里一键装：

| 工具 | 用途 | 平台 |
| --- | --- | --- |
| yt-dlp | B 站 / YouTube 解析与音轨下载 | 全平台一键装 |
| ffmpeg | 音频转码为 16kHz 单声道再送转写 | Windows 一键装；macOS 用 Homebrew / PATH；Linux 用包管理器 |
| FunASR (SenseVoiceSmall) | 完全离线的本地语音转写 | Windows（Python，含说话人分离）；macOS Apple Silicon（GGUF，无分离）；其余平台配云端 `audioText` |

FunASR 装完会自动写入内置 Provider 并接管 `audioText` 路由；服务按需拉起，不常驻。

Windows 本地转写引擎可独立检查更新。每次实际升级都备份当前 `env`，不复用上次环境，也不复制语音模型和 Python 运行时。升级前会在停止服务之前检查引擎所在磁盘：按文件分配空间估算备份，并为下载、解包、新旧依赖共存预留两份环境大小（至少 1 GiB）加 512 MiB 余量；备份完成后再检查一次。预算是估算，其他程序仍可能在更新期间占用空间，后续写入失败仍会尝试回滚。pip 临时文件固定在本次备份目录，更新时禁用额外的下载缓存。

正常升级或成功回滚后清理本次备份和临时文件；清理失败会在结果详情中提示，下次实际更新重试。`update.json`（v2）记录状态、原版本、目标版本及根目录/备份目录的文件系统身份。历史备份只有明确标记为可丢弃、目录身份一致且内容检查通过时才会自动清理；中断、恢复失败、旧格式、缺少/损坏记录、目录连接/链接、额外的顶层文件均保留。不会凭进程退出、目录名、年龄或旧版本号推断可删；`pip-repair-backup-*` 手动副本也保留。`env`、`tmp` 和 `failed-env` 是更新器管理的工作目录，不应存放个人文件。回滚先将当前依赖环境移入本次备份的 `failed-env`，再复制旧环境；恢复失败时保留两份现场和原安装记录，不先删除当前环境。文件系统校验不能替代对同权限进程并发篡改目录的操作系统隔离。
