# 文章页：阅读优先重构

## 设计依据

用户提供的文章页截图中，内容标签、阅读版本、AI 页面管理和任务恢复分别占用一层区域；整段模型错误常驻，旧成品与新任务失败的对象也不明确。本次采用用户选定的“阅读优先，界面简洁安静”，保留来源和编辑能力，减少常驻操作。

## 阅读与操作

- 文章头保留标题、分类、来源、字数和必要的保存状态；标签、配图、媒体与来源版本进入“文章信息与工具”。工具区为非模态区域，关闭时不卸载当前条目的媒体和进行中的操作，子弹层自行处理 Esc 和焦点。
- 正文/文字稿/讨论等内容标签，与原文/AI 阅读、编辑、目录、查找合并到同一工具栏。窄区域允许操作换行，内容标签不会被挤成单字。
- Markdown 阅读列限宽，字号仍随全局字体设置变化；标题在窗口缩放、侧栏变化时重新计算高度，最多三行后内部滚动。
- AI 图片、参考资料、导出、版本恢复及删除集中到“阅读页设置”，明确它们操作的是 AI 阅读版本。
- 原文编辑保留独立草稿、并发更新检测与保存失败保护；论坛总结只更新总结段，来源元数据和主帖/回复不受影响。
- 后台生成完成不会抢走用户主动选择的原文或编辑视图。首次打开已有 AI 成品时的默认阅读行为保留。
- 回收站仍可阅读与导出，编辑、重新采集、任务恢复等写入操作不可用。

## 提示与恢复

| 状态 | 页面行为 |
| --- | --- |
| 已有成品，正在更新 | 短摘要说明当前仍可阅读已有版本 |
| 已有成品，本次失败 | 说明“当前显示上次生成的版本”，详细原因与用量折叠 |
| 没有成品，生成中/失败 | 只显示一个任务状态区域，原文入口保持可用 |
| 正在阅读原文 | AI 失败与版本提示不占用正文空间 |
| 资料查证失败 | 单一“补查资料并继续”动作；没有重复的同义恢复按钮 |
| 补查额度耗尽 | 隐藏无效恢复动作；明确提供不联网继续或重新生成 |
| 采集内容待复核 | 独立短提示，展开后查看缺口和标记已复核 |

联网取材不再仅凭搜索服务返回文本超过 200 字就跳过正文抓取。选中的来源尝试获取实际正文；资料不足时根据缺口补查。初始查询最多 3 次，最多追加 2 轮、6 次搜索，每轮最多选择 8 篇来源。搜索、来源选择、正文读取和充分性判断分别保存检查点。重复恢复不会无限重放已完成请求，也不会静默切换为不联网生成。

默认新页面的设计提示改为克制排版、适度标题和首屏可见正文；用户明确填写的设计偏好仍优先，已保存页面不会自动重绘。
