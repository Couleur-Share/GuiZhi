# AI 阅读页组件与动态图解

阅读页继续由 AI 按文章内容设计 HTML/CSS。归知提供可复用组件、生成阶段图形编译以及受控的动画播放；普通文章无需强制添加图形。

## 已接入的能力

| 来源 | 固定版本 | 用途 | 阅读与导出 |
| --- | --- | --- | --- |
| daisyUI | 5.7.28 | 时间轴、步骤、提示、徽标、统计、表格、卡片 | 按组件内嵌带前缀 CSS |
| Mermaid | 11.17.2 | 流程、时序、状态、思维导图 | 保存规范化 SVG，不加载编译库 |
| Anime.js | 4.5.0 | 描线、显现、沿路径运动、路径形变 | 仅动画页内嵌固定运行时 |
| ECharts | 6.1.0 | 柱状、折线、面积、饼图、环形图 | SVG 和有限 CSS 入场动画 |

图表没有悬浮提示、缩放和筛选；数据表始终可用。无图导出只去掉栅格配图，SVG 图形继续保留。上述库的许可证和归属文本保存在 `docs/licenses/reading-graphics`；构建输出保留第三方许可注释。

## 数据与生成

设计响应新增可选 `visuals`、`animations`。视觉扩展版本为 1，沿用阅读页格式版本 2，不修改 SQLite 表。旧页没有这些字段时保持原行为。

`visuals` 对应唯一的 `data-reading-visual` 容器与文字说明；Mermaid 接受固定图类型的描述，图表接受分类、系列、单位和编辑稿中的原句依据。数值必须在依据原句中出现，不开放任意图表 option 或执行函数。

图形定义保存在 reconstruction，编译结果保存在 design.visualResults。结果携带定义摘要和编译器版本，重新打开与导出仅做校验和组装，不再次调用图形库。单图成功或失败都保存检查点；继续任务跳过已有结果，只重试失败部分。

图形编译通过隔离的 Electron 窗口完成，临时会话不使用正式用户数据；仅加载固定编译页，禁用网络、导航、下载、权限和 Node。每图十秒、每页六十秒，取消或异常时回收窗口与临时文件。

第三方输出与模型 HTML 使用不同的校验入口。图标只展开页内定义，装饰滤镜移除；模型仍不能输出 use、filter、foreignObject、script 或事件属性。规范化处理中文 ID、重复定义、局部引用、主题颜色、CSS 作用域和动画名称。备份或数据库中的编译结果也不能绕过校验。

## 动画与阅读器

动画只接受四个固定预设和当前 SVG 内的元素 ID。每步 400–1600 毫秒，单图总时长最多八秒；文字标签不能作为隐藏或移动目标。

默认前三个动画图形进入可见区域时各播放一次，同时只播放一个。应用内使用外层滚动容器传来的真实可见区域；独立 HTML 使用自身视口。离开视口和页面隐藏时暂停，手动暂停后不会自动恢复。

每图提供播放、暂停、继续和重播，页面提供动画总开关。关闭动画、系统减少动态效果、打印或初始化失败时，显示完整静态图。导出包含的脚本通过 CSP 哈希固定，不携带应用桥接、访问密钥或网络依赖。

## 验证入口

- 单元测试：reading-visuals、reading-visual-document、reading-visual-recovery，以及已有阅读页、备份和任务测试。
- UI：设置 `GUIZHI_GRAPHICS_VALIDATION=1`，运行根目录 `pnpm shot`，steps 使用 `apps/desktop/tests/e2e/reading-graphics-shots.mjs` 的绝对路径。
- 可选真实模型验收：设置 `GUIZHI_GRAPHICS_LIVE_CONFIG` 为现有模型配置文件路径。仅只读取得当前文本模型参数，不复制配置、不连接正式库；使用明确标记为虚构的教学材料，最多十二次文本请求，不联网搜索。
- 测试入口由构建常量控制，只在隔离验收构建中存在，正式构建删除入口及测试模块。

截图、状态断言、真实模型结果与体积记录应分别报告，不能把固定样例验收当成真实模型生成成功。
